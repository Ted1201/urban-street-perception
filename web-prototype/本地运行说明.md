# 在自己的电脑上运行网站

推荐：双击项目根目录或“成果汇总_第一版/11_Web可视化原型”中的“离线打开网站.cmd”。也可直接打开本目录 `dist/macau-streets.html`。此方式无需联网、代理、VPN、Python服务或启动窗口，直接在浏览器中读取本机文件。请保留整个 dist 文件夹。

数据更新后运行 `python web-prototype/build_offline.py` 重新生成离线页面。离线页面的数据内嵌在HTML中，图片、样式和脚本仍使用同目录文件。托管部署继续使用 index.html 和 data/project.json。

下面是可选的本地 HTTP 服务方式：

1. 双击项目根目录的“启动毕业设计网站.cmd”，或本目录的“启动网站.cmd”。
2. 浏览器会自动打开 http://127.0.0.1:8765 。启动窗口保持打开。
3. 停止时在启动窗口按 Ctrl+C，或关闭启动窗口。下次双击即可重新启动。

目前只允许本机访问；这个地址不能发给老师作为远程访问链接。可以在自己的电脑上现场演示。电脑关机或服务停止后无法继续访问。

网页、地图、照片、筛选、对比和已有预测结果都由本地文件提供，不需要腾讯云、宝塔或域名。当前预测页展示已有实验结果，不会在网页中重新运行 Python 模型。

后续迁移到静态托管平台时，上传完整的 dist 文件夹内容即可；其中 index.html、data 和 photos 的相对位置要保留。Python 启动脚本无需上传。
