# 澳门街道环境评价

公开 Web 可视化原型。站点身份保存在 `.openai/hosting.json`；部署结果与在线地址见成果目录中的部署记录。

## 页面

- 街道地图：区域、道路等级、结构类型、名称/编号筛选，指标切换，地图缩放平移，道路导出。
- 街道详情：道路属性、两类代理指数、分项标准分、可用图片数、街景缩略图分页和质量提示。
- 指标对比：最多同时比较四条道路的指数、原始指标和样本数。
- 预测实验：两种目标、两种特征集、五类模型、训练/验证/测试集切换；误差表、散点图、逐道路预测与导出。MLP为固定种子42的已完成结果，不在页面中训练模型。

## 本地运行

双击项目根目录的“启动毕业设计网站.cmd”，或本目录的“启动网站.cmd”，浏览器会自动打开 `http://127.0.0.1:8765`。启动窗口保持打开，按 Ctrl+C 或关闭窗口可停止。详细说明见“本地运行说明.md”。本地预览服务只监听本机，后续托管可直接上传完整 `dist` 内容。

## 更新数据

在原 `E:/毕业设计` 项目中运行 `C:/Users/25142/anaconda3/python.exe web-prototype/export_data.py`，然后验证并重新部署。导出器读取原 outputs 数据，不包含模型权重或原始高分辨率图片。

网站快照包含1,537条道路、5,920条街景记录、5,537张按SHA-256去重的512像素JPEG缩略图及3,500条实验预测。站点前端不依赖第三方CDN、在线底图或外部分析服务。交互图由本地脚本绘制，所有静态资源由同一站点提供。

## 指标口径

地图为道路街景坐标中位数代表位置，不是道路中心线；区域边界沿用已有研究判界文件。视觉子指数304条、完整代理指数46条，不混合排名。预测目标使用仅在训练集拟合的标准化尺度，与早期全样本指数分别解释。静态图片车辆数包含停放车辆，图像识别仍有误差。没有照片的采样点不生成缺图标记。

按用户要求公开发布，持有网址的人可直接查看网站中的缩略图、指标和实验结果。页面右上角可复制分享链接，粘贴到微信聊天。微信内置浏览器的实际兼容性需用手机核对。

## 动态效果

地图选中/悬停点有扩散光环，最多24个有评分的点轻微呼吸；页面、筛选列表、图片弹窗采用淡入过渡。缩放和平移复用SVG节点。左下角“动态效果”可手动开关并记住网页偏好；未手动设置时遵循系统减少动态效果偏好。
