# Urban Street Perception Analysis and Prediction

## Overview
This project investigates the relationship between street-level visual features and users' perceptions of urban environments in Macao.

The project combines street images, user perception ratings, geospatial analysis, and machine learning methods to compare different urban areas and predict perceived environmental scores.

## Objectives
- Visualize street-level images and user perception scores
- Compare perception scores across different locations
- Analyze relationships between visual features and user ratings
- Develop machine learning or deep learning models for perception prediction

## Data
The dataset contains:
- Street-level images from Macao
- User perception ratings
- Location-related information

Note: The original dataset is not publicly released.

## Methods
Planned methods include:
- Data preprocessing
- Exploratory data analysis
- Geospatial visualization
- Machine learning / deep learning
- Model evaluation
