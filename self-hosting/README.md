# 澳门街道网站：自己的服务器部署

现有网站可以脱离当前托管平台运行。它是纯静态网站，网页、交互代码、JSON数据和街景缩略图都在 `dist/` 中。服务器无需Python、Node.js、数据库、模型权重或ChatGPT登录服务；浏览器通过HTTP/HTTPS读取这些文件即可运行。

部署包约60MB，内含1,537条道路、5,920条图片索引、5,537张缩略图及已有模型实验结果，包含地图动态效果。原高分辨率街景和训练代码不在此包中。此版本展示已有预测，不在服务器实时训练。

## 方式一：宝塔或其他网站面板

1. 上传并解压“自有服务器部署包.zip”。
2. 在面板中新增静态网站，填入自己的域名；运行环境使用纯静态。
3. 把网站根目录设为解压目录下的 `dist`。该目录应直接包含 `index.html`、`app.js`、`style.css`、`motion.css`、`data/`、`photos/`。
4. 域名A记录解析到服务器公网IP。给该网站配置HTTPS证书，并开放该网站使用的80/443端口。
5. 用自己的域名打开网站，测试筛选、图片和预测页，再把这个域名链接发送到微信。

不要把“外层解压目录”误设为根目录，否则不能直接显示网页；`dist` 内的目录结构必须完整保留。若先用公网IP测试，可在面板中为该IP建立相应站点，再访问该IP。

## 方式二：已安装Docker和Compose的Linux服务器

上传压缩包并解压，进入含 `compose.yaml` 的目录后运行：

```bash
docker compose up -d
docker compose exec web nginx -t
```

浏览器访问 `http://服务器公网IP:8080`。需要服务器及云安全组允许对应的TCP 8080端口；若端口被其他服务占用，修改compose.yaml左侧端口后重启。本配置只启动此项目的Nginx服务。

有域名且服务器已有Nginx/宝塔时，可将该域名反向代理至 `http://127.0.0.1:8080`，由外层站点配置HTTPS；此时可将Compose端口改为 `127.0.0.1:8080:80`，仅供反向代理连接。不要直接覆盖其他网站的配置。

排查和停止：

```bash
docker compose logs --tail 50 web
docker compose down
```

Docker方式使用官方Nginx镜像，静态目录以只读方式挂载，做法参考[官方镜像说明](https://hub.docker.com/_/nginx)。`stable-alpine`是滚动标签，正式运维如需锁定环境，可在首次部署成功后记录镜像digest并固定。

## 方式三：现有Linux Nginx

把 `dist` 放到例如 `/var/www/macau-street/dist`，参考 `nginx-site.conf` 新建此站点配置，替换 `example.com` 和实际根目录。确保Nginx工作进程可读取这些文件。

先检查配置，再重载：

```bash
sudo nginx -t
sudo systemctl reload nginx
```

这是面向systemd Linux的示例；具体配置文件目录、服务管理方式取决于系统或面板。已有网站应新增独立站点配置，而非覆盖nginx主配置。配置中 `root` 与 `try_files` 的含义见[Nginx官方说明](https://nginx.org/en/docs/http/ngx_http_core_module.html#try_files)。

## 域名、HTTPS和微信分享

可先用公网IP和端口测试。有域名时解析到自己的公网IP并配置HTTPS，分享最终HTTPS地址。页面右上角的“复制分享链接”按当前网站地址生成链接，迁移后会自动复制你的域名，无需改代码。纯HTTP环境若无法自动写剪贴板，会显示可手动复制的网址。

微信内置浏览器还需在手机上实际打开核对，外部平台对域名的处理不由本网页控制。更换托管位置不自动赋予原ChatGPT账号私有访问限制；此部署配置为公开展示，与当前分享需求一致。

## 部署验收

- 打开首页能显示1,537条道路、5,920条图片记录、304/46条指数覆盖。
- 筛选“路环”后当前道路数为67。
- 道路详情能加载缩略图并打开图片弹窗。
- 预测页默认视觉目标、道路属性加背景、MLP测试集：73条，MAE11.12、RMSE13.71、R²0.471。
- 动态效果开关、地图缩放和CSV导出可用。
- 刷新带 `/#predict` 的地址仍能打开预测页。

如图像或数据不显示，首先检查 `data/project.json` 与 `photos/` 是否完整上传，以及浏览器是否返回404。不要通过双击本机HTML文件代替HTTP服务测试。

## 后续更新

在原毕业设计项目重新运行数据导出后，将最新 `dist` 整体同步到自己的服务器。网页和JSON按本配置重新验证缓存；照片文件名使用内容哈希，可长期缓存。建议更新前备份服务器上一个可用版本。

本部署包已检查静态资源和目录完整性；当前电脑未安装Docker/Nginx，未在真实目标服务器执行容器启动或 `nginx -t`。目标服务器操作需在确认系统、现有端口和域名后进行。
