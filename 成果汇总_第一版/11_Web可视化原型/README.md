# 澳门街道环境评价｜第一版Web说明

网站源代码位于仓库根目录 [web-prototype](../../web-prototype/README.md)。

下载完整仓库，在根目录执行 `python prepare_web.py`，随后打开 `web-prototype/dist/macau-streets.html`。Windows可双击根目录“离线打开网站.cmd”。缩略图从assets/thumbnails分包还原，无需联网访问网站。

已实现地图、道路详情、街景查看、道路对比、实验预测记录、误差对比和CSV导出。项目开发中，网页尚未接入真实模型推理接口。

更多信息见[仓库首页](../../README.md)和[后续任务表](../../后续任务表.md)。
