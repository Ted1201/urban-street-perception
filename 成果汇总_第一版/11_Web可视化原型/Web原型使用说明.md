# 澳门街道环境评价｜Web 可视化原型

## 本地离线访问（当前推荐）

双击同目录“澳门街道环境评价.lnk”，或解压源码包后打开dist/macau-streets.html。

## 原在线访问（历史入口）

当前入口已改为本地文件 `web-prototype/dist/macau-streets.html`；历史发布地址保留在部署记录中。

按用户要求改为公开访问。持有原在线链接的人可直接打开，已用不带Cookie或登录凭据的请求验证成功。复制网址发送至微信聊天即可分享；页面右上角也可复制链接。微信内置浏览器尚未实测，如遇微信拦截，可复制链接到手机浏览器打开。

## 页面功能

| 页面 | 已实现内容 |
| --- | --- |
| 街道地图 | 名称/编号搜索、区域/道路等级/结构筛选、两类指标切换、缩放平移、点选道路、筛选数据导出 |
| 街道详情 | 道路属性、标准分和代理指数、可用样本数、质量提示、街景分页和图片弹窗 |
| 指标对比 | 最多4条道路并列比较指数、分项标准分、原始值及样本数 |
| 预测实验 | 两个目标、两类特征、均值/线性/森林/梯度提升/MLP模型切换；训练/验证/测试集合选择；MAE/RMSE/R²、散点图、逐道路预测和CSV导出 |

预测结果来自已有冻结实验，MLP展示固定主种子42结果，不在网站中重新训练。切换任务时，MLP优先显示该任务验证选择的特征集。用户仍可查看其他特征集的对照结果。

## 数据快照与口径

包含1,537条道路、5,920条实际街景记录、5,537张不同内容的512像素缩略图，以及3,500条模型预测。原图保留在本地研究项目中。图像按需加载，保留图片编号、道路关联和质量复核信息。

地图显示道路街景坐标中位数的代表位置，不是道路中心线；边界沿用既有研究判界。指标仅反映当前定义的环境质量代理，视觉子指数304条、完整指数46条。空指数与低分不同。原本没有图片的采样点不另外生成缺图标记。

地图使用第一版全样本参考尺度；预测目标使用训练集拟合的尺度，两者不可直接混用。主分析MLP测试MAE11.12、RMSE13.71、R²0.471；完整目标验证选择的MLP测试MAE13.65，测试样本仅7条。可见车辆包含停放车辆，图像识别仍有误差。

## 本地运行与源码

原始网站工程位于 `E:/毕业设计/web-prototype`，包含 `dist/`（可独立托管的网页及全部展示资源）、导出脚本和数据核验脚本。

解压“Web原型源码与资源.zip”后，进入“澳门街道环境Web原型”目录，运行“启动本地预览.ps1”；或用任意Python解释器运行 `python -m http.server 8765 --bind 127.0.0.1 --directory dist`，再打开 `http://127.0.0.1:8765`。结束时按Ctrl+C。index.html需通过HTTP服务打开；本次新增的dist/macau-streets.html已内嵌数据，可直接双击离线打开，无需VPN或服务器。

更新数据时在完整毕业设计项目中运行 `web-prototype/export_data.py`，再运行 `web-prototype/verify_export.py`。导出器会读取原 outputs 表格并生成展示资源。在线更新还需重新发布，单纯修改本地文件不会改变在线版本。

本次验收记录包含搜索空状态、路环筛选、道路详情、街景弹窗、道路比较、地图缩放、预测切换与CSV下载。导出数据另核对了图片资源完整性和模型测试误差。

## 动画过渡更新

地图选中点与悬停点有扩散光环，最多24个有指标的点轻微呼吸。页面、筛选列表和图片弹窗有淡入过渡。缩放/平移只移动现有图层，避免重绘所有点。左下角“动态效果”可手动开关并保存偏好；未手动设置时遵循系统减少动态效果设置。
