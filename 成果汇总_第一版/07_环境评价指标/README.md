# 环境评价指标成果

本文件夹包含本阶段的 9 份成果。当前研究目标为街道环境质量代理评价，建议先阅读[代理目标定义](环境质量代理目标定义.md)。

| 文件 | 用途 |
| --- | --- |
| [指标体系与计算规则.md](指标体系与计算规则.md) | 指标方向、标准化、权重、分组、缺值处理和使用限制 |
| [街道环境评价指标全表.csv](街道环境评价指标全表.csv) | 全部 1,537 条道路的原值、标准分、指数与分组 |
| [环境评价指标分布.png](环境评价指标分布.png) | 指数及分项分布、分组数量和权重敏感性 |
| [结构等级分组统计.csv](结构等级分组统计.csv) | 按道路结构类型和等级统计完整指数分组 |
| [澳门街道环境评价指标.ipynb](澳门街道环境评价指标.ipynb) | 已运行的 Jupyter Notebook，可在当前 PyCharm 项目内打开 |
| [build_environment_indicators.py](build_environment_indicators.py) | 本次计算脚本的归档副本 |
| [计算参数.json](计算参数.json) | 标准化分位数、权重和分组阈值 |
| [结果摘要.json](结果摘要.json) | 样本覆盖和分组结果计数 |

建议先阅读指标规则，再使用指标全表和分布图。完整指数有 46 条道路，视觉子指数有 304 条；空值不代表低分。完整指数与视觉子指数分别比较。

复算时在当前 `E:/毕业设计` 项目中运行 Notebook；它调用项目 `scripts/build_environment_indicators.py` 并读取原始成果目录。重新计算后的输出保存在 `outputs/environment_indicators_v1`，更新归档时需同步到本文件夹。
