# 第2周｜道路属性字段说明

来源：RAR 包内 `P-30M-MACAUPST.xlsx` 的 `gis_osm_roads_free_1_123_Genera` 工作表，共 6,879 条记录。下表区分了可从数据直接验证的取值与依据字段名作出的解释；原始 GIS 元数据未提供的含义和单位仍需确认。

| 字段 | 实际类型 / 取值 | 用途与解释 | 质量备注 |
| --- | --- | --- | --- |
| `OBJECTID` | 整数，1—6879 | 当前点记录编号；与 JPG 文件名数字部分对应 | 无空值、无重复、无断号 |
| `ORIG_FID` | 整数，1—13159 | 推测为生成点之前的原始道路要素编号 | 1,537 个不同值，可重复 |
| `osm_id` | 文本 | 推测为 OpenStreetMap 道路要素 ID | 1,537 个不同值，可重复；按文本保存 |
| `code` | 整数，5113、5114、5115 | 道路等级编码 | 与 `fclass` 一一对应：5113=primary，5114=secondary，5115=tertiary |
| `fclass` | 文本，primary / secondary / tertiary | 道路类别，分别对应一级、二级、三级道路的来源分类 | 数量依次为 3,800、1,647、1,432 |
| `name` | 文本 | 道路名称，部分含中葡双语 | 197 条为空或仅空白字符 |
| `ref` | 文本，单个空格 | 推测为道路参考编号 | 6,879 条均为空白占位符，无有效编号 |
| `oneway` | 文本，F / B / T | 来源数据中的通行方向代码 | 分别 5,932 / 929 / 18 条；代码的具体方向定义需查原始元数据 |
| `maxspeed` | 整数，0 / 30 / 40 / 50 / 60 / 80 | 来源数据中的速度字段，推测单位为 km/h | 0 有 5,278 条；不能直接解释为“无限速”，应先确认缺省编码 |
| `layer` | 整数，−2 至 5 | 推测为道路垂直层级 | 不等同于海拔；含 0 的记录 5,580 条 |
| `bridge` | 文本，T / F | 桥梁标记，推测 T=是、F=否 | T 有 1,072 条；具体编码含义需元数据确认 |
| `tunnel` | 文本，T / F | 隧道标记，推测 T=是、F=否 | T 有 226 条；未见同一记录桥隧同时为 T |
| `Shape_Length` | 小数，0.0002925442—0.0313752026 | 原始道路线要素的长度属性 | 同一来源要素的多条点记录重复；单位/坐标系未提供，不能直接当作米 |
| `POINT_X` | 小数，113.528971648—113.589930177 | 点位横坐标；数值形态为经度 | 均在经度合法范围内；具体坐标参考系统待确认 |
| `POINT_Y` | 小数，22.110420704—22.217704118 | 点位纵坐标；数值形态为纬度 | 均在纬度合法范围内；具体坐标参考系统待确认 |

道路类别、编号、空值和取值范围均由当前工作簿实测得到。字段的来源定义以原始 GIS 数据字典为准，特别是 `oneway`、`maxspeed=0`、`Shape_Length` 单位与坐标参考系统。
