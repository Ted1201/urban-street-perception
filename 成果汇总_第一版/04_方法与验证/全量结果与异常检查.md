# 澳门街景视觉特征全量提取与异常检查

## 结果范围

- 实际存在的图片记录：5,920 条，每个 `image_id` 一行；其中不同 SHA-256 图片 5,537 张，精确重复图片记录 383 条。原本没有照片的采样点不生成特征行，也不设置缺图标记。
- 推理成功 5,920 条，失败 0 条。12 个核心视觉特征及图片、采样点、道路关联字段没有缺值；相同 SHA-256 的核心特征一致。
- 完整逐图特征见 `street_view_features_full.csv`，共 52 列。绿化、建筑、天空均为有效画面像素占比；车辆、行人为静态图片中的检测数。
- 不同图片的推理时间中位数约 0.819 秒，累计推理时间约 7,708 秒。该累计值不包含模型加载、文件导出及早期断点任务间隔。

## 自动检查

| 检查结果 | 图片记录数 |
| --- | ---: |
| 自动规则未触发 | 1,842 |
| 触发至少一项质量复核规则 | 4,078 |
| 质量规则或道路等级内统计尾部值进入复核表 | 4,107 |
| 道路等级内 99.5 百分位统计尾部提示 | 149 |

复核表中的标记可以重叠，**不能相加作为错误图片数**。标记频数最高的是跨切片车辆框重叠 2,481、行人与骑行者判断不确定 981、天空与建筑在重叠切片上冲突 798、跨道路精确重复图 747、切片预测分歧较高 599、区域边界待确认 584。另有隧道场景植被识别待复核 143、桥梁场景建筑识别待复核 117。`auto_pass` 只表示未触发这些规则，不代表人工确认正确。

统计尾部只提示极端值，不删除或改写原始预测。进行分布分析时，建议按 `source_sha256` 去重，避免同一图片重复增加权重。按道路汇总时需单列跨道路重复图及道路关联待确认样本。

## 目视抽查与局限

QA 叠加图共 61 张。抽看 `MC-I000177.jpg` 可见天空中局部像素被识别成建筑；`MC-I000830.jpg` 的密集摩托车区域存在较多相邻检测框和跨切片重叠。这些例子说明当前模型在特殊场景仍有识别误差，自动规则也可能漏掉局部误识别。复核表是**候选清单**，不是准确率或误差率统计。

`motor_vehicle_count` 包括停放车辆，不能作为交通流量。`person_count` 是人物检测数，`pedestrian_count_est` 及 `pedestrian_uncertain_count` 是进一步估计。文件级图片与道路编号已关联，但具体拍摄道路尚未对全量图片独立人工核实。研究结论应区分自动提取与人工验证。

## 补充验证与可视化（2026-11-02）

`validation.json` 记录了与源表逐图核对的结果：5,920 个图片编号、采样点编号、SHA-256、相对路径和道路编号均一致，5,920 个源图片文件均可访问。核心特征无缺值，三个占比均在 0～1 内且合计不超过 1；计数无负数，精确重复图片的核心特征无冲突。异常清单中的图片编号全部包含在完整表中。这些是**结构与数值验证**，不等于模型识别准确率。

目视查看了 7 张不同场景的 QA 叠加图，作为定性检查而非随机准确率抽样。`MC-I003908` 的隧道顶部被误识别为大量植被，已触发隧道与零天空复核规则；`MC-I006654` 的施工机械与车辆框存在混淆，已进入复核；`MC-I000830` 的密集摩托车区域存在重复计数风险，已触发车辆重叠复核；`MC-I000177` 的天空局部被识别为建筑，但模型质量规则未识别这一局部错误，说明自动标记仍会漏报。`MC-I004659`、`MC-I004800` 的普通街道分割整体可读，但局部边缘仍有误差。不能依据这 7 张图估算全量准确率。

`区域与街景特征对比.png` 展示四区纳入比较的不同图片数、绿化／建筑／天空占比中位数、绿化占比分布及区域×道路等级的可见机动车数中位数。区域比较排除 168 条边界未定图片记录及跨道路精确重复图，再按 SHA-256 去重；最终纳入澳门半岛 2,398 张、氹仔 1,290 张、路氹 860 张、路环 459 张。详细交叉统计见 `区域道路等级街景特征汇总.csv`。路环 primary 组仅 2 张，不宜据此作道路等级结论。图表为模型预测结果的描述性对比，车辆数含停放车辆。

## 可复现文件

- `parameters.json`：模型、权重 SHA-256、硬件、切片、阈值与软件版本。
- `summary.json`：总数、各规则频数、运行时间和道路等级内统计阈值。
- `anomaly_review.csv`：逐图人工复核候选及优先级。
- `qa_previews/`：预测叠加图。
- `notebooks/澳门街景全量特征提取与检查.ipynb`：已运行的 Jupyter Notebook；运行环境为项目的 Anaconda Python，可在 PyCharm 中打开。
- `全量特征与异常概览.png`：Notebook 保存的特征分布与质量标记图。
- `validation.json`、`区域道路等级街景特征汇总.csv`、`区域与街景特征对比.png`：补充验证与区域对比结果。
