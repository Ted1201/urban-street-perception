# 第一版成果（V1.0）

归档日期：2026-11-08。当前项目仍在开发中，完整说明见[仓库首页](../README.md)，第二版工作见[后续任务表](../后续任务表.md)。

此目录保留第一版的数据表、报告、图表、Notebook和模型。GitHub发布时省略重复ZIP、工作站快捷方式及历史托管记录；原始照片和预训练权重未发布。现有第一版文件名中的“第13周”为既有实验阶段名称。

| 目录 | 内容 |
| --- | --- |
| 01_核心数据 | 道路、采样点、图片关联与视觉特征表 |
| 02_图表、03_分析Notebook | 基础分析与可视化 |
| 04_方法与验证 | 数据说明、质量检查与方法记录 |
| 05_复现代码 | 第一版代码快照 |
| 06_参考资料 | 课题目标说明 |
| 07_环境评价指标 | 指标定义、规则和结果 |
| 08_街道环境对比分析 | 街道比较报告与统计图表 |
| 09_基线预测模型 | 均值、线性、随机森林和梯度提升实验 |
| 10_第13周神经网络预测实验 | MLP配置、模型、学习曲线和比较结果 |

在仓库根目录运行 `python prepare_web.py`，再打开 `web-prototype/dist/macau-streets.html` 查看离线网站。当前网页读取已有预测，不执行实时推理。视觉指标覆盖304条道路，完整指标覆盖46条；完整目标测试仅7条，不作为稳定性结论。
