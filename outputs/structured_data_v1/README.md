# 澳门道路图片与采样点｜第一版结构化数据

来源：`数据集/澳门123级道路30m5920张备份照片-截至2026.1最新.rar`。完整解压文件位于 `source/`，清洗后的 UTF-8 BOM CSV 位于 `tables/`。原始包未修改。

## 表与关联

| 文件 | 粒度 | 主键 | 关联与内容 |
| --- | --- | --- | --- |
| `tables/roads.csv` | 原始道路要素，1537 条 | `road_id` | `source_orig_fid` 对应原表 `ORIG_FID`；保留道路属性、采样点数和图片数 |
| `tables/sampling_points.csv` | 采样点，6879 条 | `sample_id` | `road_id` 连道路，`image_id` 连图片；保留原 `OBJECTID`、坐标及状态 |
| `tables/images.csv` | 实际图片，5920 张 | `image_id` | `sample_id` 连采样点；含相对路径、字节数、SHA-256 和完全重复图片指针 |
| `tables/quality_issues.csv` | 逐条问题 | 无 | 用 `entity_type`、`entity_id`、`issue_code` 定位问题 |

## 编号与处理规则

- `MC-R` + 五位原始 `ORIG_FID` 是道路 ID；`MC-P` + 六位原始 `OBJECTID` 是采样点 ID；`MC-I` + 六位同号数字是图片 ID。编号由原始键确定，重新生成不会因排序变化而漂移。
- 有对应图片的采样点填写 `image_id`；没有拍摄图片的点保持该字段为空。这是源数据的正常情况，不列为质量问题。
- 道路 `name`、`ref` 去掉首尾空白后若为空，写成 CSV 空值并记入问题表。不会推测缺失名称或参考编号。
- 对原始记录（排除 `OBJECTID`）、坐标对和图片 SHA-256 分别检查重复。完全相同的图片由 `duplicate_of_image_id` 指向首个编号，原件与采样点均保留。
- 坐标先检查是否为有限数字、合法经纬度，再用宽松范围 `113.50–113.65°E, 22.08–22.25°N` 作研究区初筛。未通过者标 `needs_review`；此范围不是澳门行政边界。原数据的坐标参考系统未附说明，不做坐标转换或自动修正。
- `maxspeed=0`、`oneway` 编码与 `shape_length` 单位仍按源值保存；无元数据时不擅自解释。

## 本版核验

采样点 6879 条，图片 5920 张，文件名关联 5920 条；字节完全重复的图片 383 张，独立 SHA-256 值 5537 个。重复点记录、重复坐标、初筛异常坐标均为 0。其他问题数量见 `summary.json`。这里的重复图片仅指字节完全一致，不代表画面内容相似性检查。图片是否拍到对应道路、坐标是否落在正式行政边界内仍需后续核实。
